# Model Zoo

This directory documents every trained model in the project. **The `.keras` weight files are not committed to Git** (they are large binaries). They are either:
1. Attached to the corresponding [GitHub Release](https://github.com/dfcordero/brugada-syndrome-detection/releases), or
2. Regenerated by running the training scripts (see the root [README](../README.md)).

---

## Final models (recommended)

| File | Phase | Architecture | AUC | Recall | FP | FN | Threshold | Role |
|------|-------|--------------|:---:|:------:|:--:|:--:|:---------:|------|
| `modelo_brugada_v41.keras` | B (transfer) | CNN-Res + LSTM | **0.987** | 0.933 | 2 | 1 | 0.825 | Best AUC / first screener |
| `modelo_brugada_v42.keras` | B (transfer) | CNN-Res + GAP | 0.978 | **1.000** | 4 | 0 | 0.525 | Max sensitivity / safety net |

## Required preprocessing artifacts

The dual-input models need the feature-normalization statistics fitted on the training set:

| File | Shape | What it is |
|------|-------|-----------|
| `feat_mean.npy` | (18,) | Mean of the 18 statistical features (train set) |
| `feat_std.npy` | (18,) | Std of the 18 statistical features (train set) |

> All `.keras` and `.npy` files are git-ignored. Download the final models from Releases, or run the pipeline to regenerate everything.
